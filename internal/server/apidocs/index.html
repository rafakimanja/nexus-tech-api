Autorização

Para autenticar e testar as rotas protegidas:

  1. Abra /login, entre com o Google e copie o valor de id_token exibido após o login.
  2. Volte para esta página, abra POST /login/v2 na seção Sessão e cole esse valor no campo idToken do corpo JSON. Clique em Executar.
  3. Na resposta, copie o valor de access_token e cole no campo abaixo, sem escrever Bearer.

O token fica somente nesta página até ela ser fechada ou recarregada.

Executar uma requisição altera dados reais da API conectada. Use uma conta e um ambiente de testes.
